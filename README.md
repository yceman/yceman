## 📁 Projetos em Destaque (Ciência de Dados)

### 🌾 Previsão de Produção Agrícola (Dados IBGE Sidra)
*   **O que faz:** Pipeline completo de dados focado na coleta automatizada, tratamento e modelagem preditiva de safras e culturas brasileiras.
*   **Tecnologias:** Python, TensorFlow (Deep Learning), Pandas e Requests (Integração com a API Sidra/IBGE).
*   **Abordagem Técnico:** Coleta direta de dados históricos de produção agrícola via API do IBGE, engenharia de recursos (feature engineering) para análise de tendências sazonais e desenvolvimento de redes neurais para prever o volume de produção de culturas selecionadas.

### 🧪 Análise de Biocombustíveis & Bioprocessos (*Saccharomyces cerevisiae*)
*   **O que faz:** Análise exploratória e modelagem estatística de dados agroindustriais focados no ecossistema de produção de biodiesel.
*   **Tecnologias:** Python, Bibliotecas de Análise Estatística e Data Visualization.
*   **Abordagem Técnica:** Estudo orientado a dados analíticos avaliando o comportamento e a eficiência da levedura *Saccharomyces cerevisiae* em processos fermentativos e produtivos correlacionados à matriz energética do biodiesel.
